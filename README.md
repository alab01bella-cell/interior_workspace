# Interior Workspace

인테리어 상담 관리 SaaS의 프론트엔드 프로토타입입니다. 현재 1차 구현에는 첨부된 디자인을 기준으로 만든 반응형 홈 대시보드와 mock 데이터만 포함되어 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 검증

```bash
npm run lint
npm run typecheck
npm run build
```

Google 로그인, OAuth, Drive, Sheets, 데이터베이스, PDF 및 실제 상담목록·체크리스트 기능은 아직 구현하지 않았습니다.
